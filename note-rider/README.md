# NOTE RIDER · 琴弦骑士

骑上音符马，在五线谱桥上跟上节拍换轨挥剑，斩尽迎面扑来的弦魔。连续 8 个 Perfect 触发整行震动的「和弦斩」。

## 运行

```bash
cd note-rider
python3 -m http.server 8124
# 打开 http://127.0.0.1:8124/
```

## 操作

| 动作 | 键 / 触屏 |
| --- | --- |
| 斩击 | Space / 点击 |
| 换轨 | ↑ ↓ / 上下滑动 |
| 技能（护盾/爆发/吸血/治疗） | 1 / 2 / 3 / 4 |
| 暂停/继续 | Esc 或 P |
| 重开 | R |
| 静音 | M |

完整契约见 `docs/README.md`；交付报告见 `docs/DELIVERY.md`。
