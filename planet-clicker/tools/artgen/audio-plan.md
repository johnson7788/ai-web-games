# planet-clicker 音频素材计划

> 现状：`src/audio.js` 为纯程序化 WebAudio（tone 合成，无外部文件）。本计划只描述素材规格，不改源码；接入时保留 `audio.*` 全部接口签名与静音逻辑（`unlock()` 首次交互解锁、`setMuted(m)`、`muted` getter），`click()` 现有的随机音高微变（300+rand*80）建议保留为变体随机；采样播放同样经过 muted 门控，程序化合成保留为兜底。

## BGM

- 曲风：太空 ambient（space ambient / ambient electronica），无强节拍
- BPM：自由速度，约 60 的脉冲感；调式：D 多利亚，悬浮不解决
- 情绪：浩瀚、宁静、缓慢积累的满足感
- 编制：宽体 pad  drone、颗粒合成星尘纹理、缓慢滤波扫频、偶发深空声呐 ping、极低频 sub 心跳
- 结构：64 小节无缝长 loop（约 2min，避免放置游戏循环感疲劳），另出 32 小节 "menu" 变体；无鼓组、无突兀瞬态
- 交付：OGG + M4A 双格式，44.1kHz，响度 -18 LUFS，循环点零交叉对齐

## 音效清单（映射现有 audio.js 方法名）

| 方法 | 质感描述 | 规格 |
|---|---|---|
| `click()` | 点击星球：柔软能量噗声 + 高频叮泛音，水滴/等离子质感，音高轻微随机，耐高频重复 | ~100ms，3 个音高变体 |
| `buy()` | 购买升级：上行双音水晶叮咚（C5→G5），干净明亮带空间混响尾 | ~200ms |
| `deny()` | 能量不足：低哑短嗡，柔和拒绝感不刺耳 | ~150ms |
| `planet()` | 解锁新星球：C5-E5-G5-C6 上行钟琴 fanfare + 星云扫频 shimmer + 深沉轰鸣落底，仪式感强 | ~1.2s |

## 接入约束

- 方法名、参数、调用时机一律不变；`click()` 保留随机音高微变避免机械感。
- 所有采样经统一 gain 总线，`setMuted(true)` 时立即静音（含 BGM）。
- 点击音是最高频事件，峰值响度控制在 -12 LUFS 以下且尾音短；首次 `unlock()` 后才允许起播。
