# flag-painter 音频素材计划

> 现状：`src/audio.js` 为纯程序化 WebAudio（tone 合成，无外部文件）。本计划只描述素材规格，不改源码；接入时保留 `audio.*` 全部接口签名与静音逻辑（`unlock()` 首次交互解锁、`setMuted(m)`、`muted` getter），`paint()` 现有的随机音高微变（440+rand*60）建议保留为变体随机；采样播放同样经过 muted 门控，程序化合成保留为兜底。

## BGM

- 曲风：轻快木琴世界风（xylophone / marimba world-lite），地理课堂的环球旅行感
- BPM：104；调式：G 大调，明亮友好
- 情绪：轻快、好奇、温和的竞猜节奏，不催促
- 编制：木琴与马林巴主奏、拨弦贝斯、沙锤与铃鼓轻打击、偶发手风琴/卡林巴点缀呼应世界风，无重鼓
- 结构：16 小节无缝主 loop（约 37s），A 8 + B 8 微变奏；另出 8 小节 "menu" 变体
- 交付：OGG + M4A 双格式，44.1kHz，响度 -15 LUFS，循环点零交叉对齐

## 音效清单（映射现有 audio.js 方法名）

| 方法 | 质感描述 | 规格 |
|---|---|---|
| `click()` | 轻柔 UI 咔哒，木质指尖触感 | <60ms |
| `paint()` | 涂色带：湿润画笔轻扫 + 木琴单音，音高轻微随机，手感顺滑 | ~120ms，3 个音高变体 |
| `correct()` | 答对国旗：C5-E5-G5 木琴上行三连音，明亮肯定，带轻微铃泛音 | ~350ms |
| `wrong()` | 答错：两段下行闷木鱼 + 柔和失谐嗡音，温和提示不惩罚感 | ~300ms |
| `done()` | 完成一轮：C5-E5-G5-C6 木琴上行 fanfare + 沙锤扫尾 + 轻快掌声音色层，课堂庆祝感 | ~1s |

## 接入约束

- 方法名、参数、调用时机一律不变；`paint()` 保留随机音高微变。
- 所有采样经统一 gain 总线，`setMuted(true)` 时立即静音（含 BGM）。
- 答对/答错音效瞬态要清晰可辨但峰值克制；首次 `unlock()` 后才允许起播。
