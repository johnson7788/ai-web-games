# color-clash 音频升级计划

UNO 式卡牌。风格定义：upbeat casual lounge（轻快休闲酒廊）+ 清脆利落的卡牌音效。
本文件只做规划，不生成、不改 `src/`。所有声音最终仍通过现有 `src/audio.js` 的 `audio.*` 接口播放。

## 接口与静音约束（必须保留）
- 保留现有 `audio` 导出对象的全部方法签名：`unlock / setMuted / get muted / click / play / draw / special / win / lose`。
- 保留首次交互解锁逻辑（`unlock()` → `ac()` 创建/恢复 AudioContext）与 `muted` 静音开关；任何新实现都必须在 `muted === true` 时静音。
- 升级方式（后续实现，二选一，均不改调用方）：
  1. 在 `audio.js` 内部把每个方法换成播放预生成音频文件（仍走同一 AudioContext / 同一静音判断）；或
  2. 保留程序化合成但增强音色。
- 不新增对外方法名，不改 `src/` 其它文件对 `audio.*` 的调用。

## BGM
- 曲风：upbeat casual lounge（轻快休闲酒廊），轻松友好的卡牌游戏之夜氛围。
- BPM：100（中速、轻盈摇摆）。
- 调式：C 大调（C major），明亮干净，带少量七和弦色彩。
- 情绪：轻松、愉悦、微竞争；不抢戏，适合长时间对局循环。
- 编制：柔和电钢琴（Rhodes）和弦、颤音琴旋律点缀、拨弦贝斯、刷鼓轻 swing、偶尔木吉他扫弦与 finger snap。
- 循环：32 小节无缝循环（约 77 秒 @100BPM，4/4），首尾和声与律动对齐，避免接缝。
- 响度：背景化，约 -18 LUFS，给卡牌音效留头空间。

## 关键音效清单（映射现有方法名）
| 方法 | 触发 | 质感描述（供 AI 生成或程序化） |
| --- | --- | --- |
| `click` | UI 点击/按钮 | 短促干净的轻叩“嗒”，660Hz 附近，50ms，轻巧，音量低。 |
| `play` | 打出一张牌 | 清脆的卡牌拍桌“啪” + 短促上行三角音（523Hz），60ms，干脆有确认感，像纸牌甩落绿呢。 |
| `draw` | 摸牌 | 轻柔的纸牌摩擦“唰” + 下行三角音（330Hz），80ms，高通噪声为主，表示抽牌入手。 |
| `special` | 功能牌（skip/reverse/draw2/wild） | 明亮上行双音方波“叮-叮”（784→988Hz）+ 细微魔法闪光，80–100ms，俏皮强调特殊效果。 |
| `win` | 获胜 | 四音上行明亮凯旋短句（523→659→784→1047Hz）+ 轻快铃琴收尾，约 0.6s，欢快庆祝。 |
| `lose` | 落败 | 三音下行温和泄气短句（330→220→147Hz），约 0.7s，轻松挫败而非沉重，符合休闲基调。 |

## 备注
- 万能牌变色可在 `audio.js` 内部用 `special` 的变体（叠加四色对应音高）表现，但必须仍由现有方法触发且受 `muted` 控制，不改接口。
- 所有音效短促、清脆、可高频叠播；峰值留余量防削波。
