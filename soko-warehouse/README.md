# SOKO WAREHOUSE

> 仓库推手 · 霓虹街机推箱子

把每只霓虹货箱推进绿色泊位。绕开岩石、卡准步数、连击上分。

## 运行

```bash
cd soko-warehouse
python3 -m http.server 8124
# 打开 http://127.0.0.1:8124/
```

零构建、零依赖、零外链。`index.html` + ES Module 纯静态。

## 操作

| 动作 | 键 / 触控 |
| --- | --- |
| 移动 | 方向键 / WASD / 点身边一格 |
| 回退一步 | Z 或 HUD `↩` 按钮 |
| 重开本关 | R 或 HUD `⟳` |
| 暂停 / 继续 | Esc / P |
| 静音 | M |
| 菜单 | HUD `☰` |

## 规则

- 4 方向移动；墙、岩石不可通过。
- 前方有货箱则推；箱子后方是墙/岩石/箱子则推不动（人也原地不动）。
- 所有货箱落上绿色泊位即过关；步数超限失败。
- 星级按步数对照 `par`（最优解）评定；连续推箱触发连击。

## 语言

- 默认英文；标题/暂停屏下拉可切中文。`?lang=zh` 可覆盖。
- 文案走 `config/locales.js`；en 与 zh 完整。
