# escape-choice 音频升级计划

Henry Stickmin 式火柴人越狱。风格定义：sneaky comedic heist jazz（鬼祟喜剧劫案爵士）+ 卡通 slapstick 音效。
本文件只做规划，不生成、不改 `src/`。所有声音最终仍通过现有 `src/audio.js` 的 `audio.*` 接口播放。

## 接口与静音约束（必须保留）
- 保留现有 `audio` 导出对象的全部方法签名：`unlock / setMuted / get muted / click / choice / fail / win`。
- 保留首次交互解锁逻辑（`unlock()` → `ac()` 创建/恢复 AudioContext）与 `muted` 静音开关；任何新实现都必须在 `muted === true` 时静音。
- 升级方式（后续实现，二选一，均不改调用方）：
  1. 在 `audio.js` 内部把每个方法换成播放预生成音频文件（仍走同一 AudioContext / 同一静音判断）；或
  2. 保留程序化合成但增强音色。
- 不新增对外方法名，不改 `src/` 其它文件对 `audio.*` 的调用。

## BGM
- 曲风：sneaky comedic heist jazz（鬼祟喜剧劫案爵士），潜行 + 滑稽，像卡通版《碟中谍》配爵士。
- BPM：110（中速、带 swing 的蹑手蹑脚律动）。
- 调式：A 小调（A minor），带爵士经过音与半音下行“潜行”贝斯线。
- 情绪：鬼祟、紧张又滑稽；潜行时压低、选择/转折时俏皮上扬，失败时短暂泄气。
- 编制：拨弦低音提琴（walking bass）、刷鼓（brushed snare + hi-hat swing）、弱音小号（harmon mute）俏皮短句、电钢琴/颤音琴点缀、偶尔木鱼或响指打拍。
- 循环：32 小节无缝循环（约 70 秒 @110BPM，4/4 swing），首尾律动与和声对齐，避免接缝。
- 响度：背景化，约 -18 LUFS，给 slapstick 音效留头空间。

## 关键音效清单（映射现有方法名）
| 方法 | 触发 | 质感描述（供 AI 生成或程序化） |
| --- | --- | --- |
| `click` | UI 点击/按钮 | 短促干净的木鱼/响指“嗒”，660Hz 附近，50ms，轻巧俏皮，音量低。 |
| `choice` | 选中一个分支选项 | 两段上行“叮-咚”颤音琴/拨弦（440→587Hz），60–70ms，鬼祟又肯定，像“就这么干”。 |
| `fail` | 越狱失败被抓 | 三音下行锯齿泄气短句（330→220→147Hz）+ 卡通“哇哦”下滑哨音，约 0.6s，滑稽挫败而非恐怖。 |
| `win` | 逃脱成功 | 四音上行明亮凯旋短句（523→659→784→1047Hz）+ 轻快爵士收尾甩音，约 0.6s，自由欢快。 |

## 备注
- 可在 `audio.js` 内部为不同场景（ sewer/roof/truck 等）叠加极轻环境底噪（滴水/风声/引擎），但必须仍由现有方法触发且受 `muted` 控制，不改接口。
- 所有音效短促、卡通化、可叠播；峰值留余量防削波。
