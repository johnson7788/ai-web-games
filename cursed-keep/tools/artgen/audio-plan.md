# cursed-keep 音频升级计划

暗紫诅咒塔防。风格定义：brooding dark-fantasy orchestral（阴郁暗黑奇幻管弦）+ 紧凑利落的战斗音效。
本文件只做规划，不生成、不改 `src/`。所有声音最终仍通过现有 `src/audio.js` 的 `audio.*` 接口播放。

## 接口与静音约束（必须保留）
- 保留现有 `audio` 导出对象的全部方法签名：`unlock / setMuted / get muted / click / shoot / kill / splash / build / upgrade / leak / win / lose`。
- 保留首次交互解锁逻辑（`unlock()` → `ac()` 创建/恢复 AudioContext）与 `muted` 静音开关；任何新实现都必须在 `muted === true` 时静音。
- 升级方式（后续实现，二选一，均不改调用方）：
  1. 在 `audio.js` 内部把每个方法换成播放预生成音频文件（仍走同一 AudioContext / 同一静音判断）；或
  2. 保留程序化合成但增强音色。
- 不新增对外方法名，不改 `src/` 其它文件对 `audio.*` 的调用。

## BGM
- 曲风：brooding dark-fantasy orchestral（阴郁暗黑奇幻管弦），塔防氛围，紧张但不吵闹。
- BPM：70（缓慢、压迫的行进感）。
- 调式：D 小调（D minor），带少量弗里几亚色彩的低音下行。
- 情绪：阴郁、诅咒笼罩、暗流涌动；波次来临时压迫感增强，但整体保持可长时间循环的背景张力。
- 编制：低音弦乐组（大提琴/低音提琴）持续音与下行音型、法国号弱奏长音、定音鼓轻击、低音木管（巴松）点缀、少量金属打击（钟琴/铁砧）与隐约合唱垫底。
- 循环：32 小节无缝循环（约 110 秒 @70BPM，4/4），首尾和声与力度对齐，避免循环接缝爆音。
- 响度：背景化，约 -18 LUFS，留出头空间给战斗音效。

## 关键音效清单（映射现有方法名）
| 方法 | 触发 | 质感描述（供 AI 生成或程序化） |
| --- | --- | --- |
| `click` | UI 点击/选塔位 | 短促柔和的木质/石质轻叩，660Hz 附近，50ms，干净无尾音，音量低。 |
| `shoot` | 箭塔开火 | 极短的弓弦释放 + 破空“嗖”声，明亮偏高频，40ms，干脆利落，可叠加轻微水晶铃音。 |
| `kill` | 敌人被击杀 | 小型“噗”爆裂 + 一缕亡灵消散的嘶嘶气声，三角波主体 + 短噪声，60ms，带轻微下行音高。 |
| `splash` | 炮塔溅射爆炸 | 低频闷响“咚” + 宽频噪声爆散，120Hz 正弦下坠 + 180ms 低通噪声，厚重有冲击但不刺耳。 |
| `build` | 建塔 | 两段上行石木砌筑声/风铃音（392→587Hz），70–90ms，温暖肯定，表示落成。 |
| `upgrade` | 升级塔 | 更明亮的上行双音（523→784Hz）+ 细微魔法闪光嘶声，表示强化完成。 |
| `leak` | 敌人漏入终点扣血 | 低沉不祥的锯齿警示“嗡”（200Hz，160ms），带轻微失谐，传达损失与诅咒侵蚀。 |
| `win` | 通关 | 四音上行小号/钟琴凯旋短句（523→659→784→1047Hz），明亮温暖，约 0.6s，收束干净。 |
| `lose` | 失败 | 三音下行锯齿悲鸣（330→220→147Hz），阴郁下沉，约 0.7s，诅咒吞没要塞的挫败感。 |

## 备注
- 冰塔减速命中可复用 `shoot` 的变体（后续如需更冷音色，在 `audio.js` 内部按塔类型微调，不改接口）。
- 所有音效短促、可高频叠播，避免长尾占用声道；峰值留足余量防止叠播削波。
