# chess-master 音频升级计划

暖木经典国际象棋。风格定义：calm solo-piano classical（宁静独奏钢琴古典）+ 温润木质棋子音效。
本文件只做规划，不生成、不改 `src/`。所有声音最终仍通过现有 `src/audio.js` 的 `audio.*` 接口播放。

## 接口与静音约束（必须保留）
- 保留现有 `audio` 导出对象的全部方法签名：`unlock / setMuted / get muted / click / move / capture / castle / check / win / lose`。
- 保留首次交互解锁逻辑（`unlock()` → `ac()` 创建/恢复 AudioContext）与 `muted` 静音开关；任何新实现都必须在 `muted === true` 时静音。
- 升级方式（后续实现，二选一，均不改调用方）：
  1. 在 `audio.js` 内部把每个方法换成播放预生成音频文件（仍走同一 AudioContext / 同一静音判断）；或
  2. 保留程序化合成但增强音色。
- 不新增对外方法名，不改 `src/` 其它文件对 `audio.*` 的调用。

## BGM
- 曲风：calm solo-piano classical（宁静独奏钢琴古典），书房沉思氛围，类似萨蒂/德彪西的简约钢琴小品。
- BPM：60（极缓、自由速度感，rubato）。
- 调式：降 E 大调（E-flat major），温暖柔和，带少量延伸和弦色彩。
- 情绪：宁静、专注、典雅；不抢思考，适合长时间对弈循环。
- 编制：独奏钢琴（柔和触键、弱音踏板），左手分解和弦琶音、右手稀疏旋律，无其它乐器，留白充足。
- 循环：32 小节无缝循环（约 128 秒 @60BPM，4/4），首尾和声与踏板残响对齐，避免接缝。
- 响度：背景化，约 -20 LUFS，极轻，给木质棋子音效留头空间。

## 关键音效清单（映射现有方法名）
| 方法 | 触发 | 质感描述（供 AI 生成或程序化） |
| --- | --- | --- |
| `click` | UI 点击/按钮 | 短促柔和的轻叩“嗒”，660Hz 附近，50ms，干净，音量低。 |
| `move` | 落子（普通走子） | 温润木质棋子轻放木盘的“笃”声，短噪声 + 300Hz 正弦轻击，50ms，柔和有质感。 |
| `capture` | 吃子 | 更厚实的木质碰撞“咔”+ 低频闷响（180Hz），90ms，略带重量感，表示移除对方棋子。 |
| `castle` | 王车易位 | 两声连续木质轻放“笃-笃”（间隔 80ms），表示王与车同时移动，干净利落。 |
| `check` | 将军 | 清亮警示双音方钟“叮-咚”（880→660Hz），100–120ms，醒目但不刺耳，提示王受威胁。 |
| `win` | 获胜 | 四音上行明亮钢琴/钟琴凯旋短句（523→659→784→1047Hz），约 0.6s，典雅庆祝。 |
| `lose` | 落败 | 三音下行温和钢琴泄气短句（330→220→147Hz），约 0.7s，沉静克制，符合古典基调。 |

## 备注
- 所有音效以木质/钢琴质感为核心，短促、温润、可叠播；峰值留余量防削波。
- 不引入嘈杂或电子感音色，保持书房古典氛围统一。
