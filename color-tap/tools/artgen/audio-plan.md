# color-tap 音频素材计划

> 现状：`src/audio.js` 为纯程序化 WebAudio（tone 合成，无外部文件）。本计划只描述素材规格，不改源码；接入时保留 `audio.*` 全部接口签名与静音逻辑（`unlock()` 首次交互解锁、`setMuted(m)`、`muted` getter），特别注意 `fill(step)` 的 step 参数语义（音高随步数爬升）必须保留；采样播放同样经过 muted 门控，程序化合成保留为兜底。

## BGM

- 曲风：lo-fi 八音盒（music box + lo-fi hip hop 底色），放松助眠系
- BPM：72；调式：C 大调 / A 小调交替，五声倾向减少紧张感
- 情绪：深夜画室的安静、专注、治愈
- 编制：八音盒主奏（带轻微机械滚筒噪声）、柔和 Rhodes 垫底、低保真鼓刷、黑胶底噪、偶发温柔风铃
- 结构：16 小节无缝主 loop（约 53s），另出 8 小节更稀疏的 "menu" 变体；避免强拍重音
- 交付：OGG + M4A 双格式，44.1kHz，响度 -16 LUFS，循环点零交叉对齐

## 音效清单（映射现有 audio.js 方法名）

| 方法 | 质感描述 | 规格 |
|---|---|---|
| `click()` | 轻柔 UI 咔哒，木质指尖触感，不抢戏 | <60ms |
| `select()` | 选中颜色：单音八音盒拨弦（C5 附近），带一点共鸣泛音 | ~100ms |
| `fill(step)` | 填格成功：八音盒单音，音高随 step 沿音阶爬升（保留 440+step*40 的上升感），8 音一循环，水润轻点质感 | ~120ms，按 step%8 预生成 8 个音高 |
| `wrong()` | 填错：低沉闷响木鱼 + 轻微失谐嗡音，温和提示不惩罚感 | ~180ms |
| `complete()` | 完成整幅画：C5-E5-G5-C6 八音盒上行琶音 + 风铃扫尾 + 柔软掌声质感层，庆祝而克制 | ~1s |

## 接入约束

- 方法名、参数、调用时机一律不变；`fill(step)` 必须继续按 step 映射音高。
- 所有采样经统一 gain 总线，`setMuted(true)` 时立即静音（含 BGM）。
- 整体音量偏轻，SFX 与 BGM 响度差 ≤4dB，保持放松氛围；首次 `unlock()` 后才允许起播。
