## 1. 牌值模型

- 一副 54 张：4 花色 × 13 点数（3..A,2）+ 大小王。
- 值域映射（`斗地主-demo/assets/Script/CardManager.js:17-83`）：`val = floor(proNum/4) + 3`，
  即 **3=3 … 10=10, J=11, Q=12, K=13, A=14, 2=15, 小王=16, 大王=17**。
- 花色：`proNum % 4` → 方片/黑桃/红桃/草花（`CardManager.js:18-67`）。
- 洗牌用 `Math.random`（`CardManager.js:86-115`）；改造版改用可复现的 `mulberry32(seed)`。

## 2. 牌型判定（核心规则）

`斗地主-demo/assets/Script/CardRule.js:1-237` + `联网斗地主/.../ddzServers/gameRule.js:12-249`。
牌型枚举（`CardRule.js:1-18`）：单(1)/对(2)/三(3)/三带一(4)/三带对(5)/顺子(6)/连对(7)/
飞机(8)/飞机带单(9)/飞机带对(10)/四带二(11)/四带两对(12)/炸弹(13)/王炸(14)。

- 顺子：≥5 张连续单、首张 `val < 15`（不含 2/王）、差值严格 1（`CardRule.js:40-49`）。
- 连对：≥6 张、偶数、连续对、不含 2（`CardRule.js:51-60`）。
- 飞机：≥6 张、3 的倍数、连续三条、不含 2（`CardRule.js:62-71`）。
- 飞机带单/带对：`CardRule.js:73-121`（带单 4 的倍数、带对 5 的倍数；三条须连续）。
- 四带二：6 张含一个 4 张（`CardRule.js:123-131`）；四带两对：8 张 = 4+2+2（`CardRule.js:133-142`）。
- 炸弹：4 张同点（`CardRule.js:144-146`）；王炸：大小王两张（`CardRule.js:26-28`）。
- 类型总判定 `typeJudge`（`CardRule.js:148-192` / `gameRule.js:12-58`）。
- **注意**：源码 `typeJudge` 的 4 张分支调用了未定义的 `isThreeWithOne`（`CardRule.js:166`、
  `gameRule.js:31`），原实现在此处有 bug；改造版必须补齐「4 张 = 炸弹或三带一」。

## 3. 叫分 / 发牌 / 地主

- 发牌 17×3 + 3 底牌（`CardManager.js:116-132`）。
- 叫分 1/2/3/不叫，分数高的当地主，无人叫重发（`MainGameLayer.js:268-316`）。
- 地主拿 3 张底牌（`MainGameLayer.js:206-267`）。
- 出牌顺序：地主先出；必须压上家；都过则出牌人重新领出（`MainGameLayer.js:185-204`）。

## 4. 出牌 / 压牌 / 结算

- 压牌：`canBeat` 逻辑隐含在 `gameRule.typeJudge` + 客户端/服务端出牌校验：
  同牌型同张数比 `val`；炸弹压一切（除王炸）；王炸最大。
- 春天/反春天：见 spec「P0 还原」；源码 demo 未完整实现计分，联网服务端 `logic/` 为骨架。

## 5. AI 策略（改造参照）

`斗地主-demo/assets/Script/AILogic.js:1-1346` + `联网斗地主/.../ddzServers/AILogic.js` +
`联网斗地主/Landlords/client/landlords-client/斗地主AI算法.txt:1-109`。

- 手牌分析：王炸→炸弹→三条/三顺→顺子→连对→对子→单牌（`AILogic.js:786-865`）。
- 叫分评分：王炸 8 / 炸弹 6 / 大王 4 / 小王 3 / 每张 2 记 2；≥7→3分、≥5→2分、≥3→1分、
  否则不叫（`AILogic.js:1259-1287`、`斗地主AI算法.txt:65-71`）。
- 跟牌：先出同型最小牌；地主在对手剩牌少时顶大；农民配合逻辑（`AILogic.js:27-291`、
  `斗地主AI算法.txt:72-109`）。
- 改造版 AI 用「技能值 skill(0..1)」量化难度：低 skill 少叫分、不拆牌、不出炸弹。

## 6. 原创改造点（spec 锁定）

1. **赛博牌局皮肤**：霓虹牌桌 + 发光牌背（程序化 Canvas，不引外素材）。
2. **签名记忆点**：炸弹出牌 = 全屏红光 + 震屏。
3. **记牌器**：按点数显示「剩余张数」计数条；AI 出牌也读它（避炸弹）。
4. **加倍**：叫分后一圈加倍（×2 每次），倍数上限 64。
5. **12 局段位**：胜利升段；底分递增 + AI 强度递进。

## 7. 事实结论

- 牌值/牌型/压牌规则可直接 1:1 转译成纯逻辑模块 `src/game/rules.js`。
- 源码的牌型判定有 4 张分支 bug，必须修正；顺子长度边界（5..12，A 为 14 上限）须补单测。
- AI 采用「评分叫分 + 贪心拆解 + 同型最小压牌」即可满足 spec 的贪心 bot 需求。
