# smash-karts 音频素材计划

> 现状：`src/audio.js` 为纯程序化 WebAudio（tone/noise 合成，无外部文件）。本计划只描述素材规格，不改源码；接入时保留 `audio.*` 全部接口签名与静音逻辑（`unlock()` 首次交互解锁、`setMuted(m)`、`muted` getter），采样播放必须同样经过 muted 门控，且保留程序化合成作为加载失败兜底。

## BGM

- 曲风：竞技电子（arena electro / synthwave 混合），驱动感强但不吵
- BPM：128；调式：E 小调（副段落可转 G 大调提亮）
- 情绪：紧张、好胜、深夜霓虹竞技场
- 编制：四拍底鼓 + 弹跳 sidechain 贝斯、锯齿波 lead arp、短促 brass stab、白噪声 riser、少量 8-bit 点缀呼应玩具卡丁车气质
- 结构：8 小节 intro loop → 32 小节主 loop（A 16 + B 16），无缝循环；另出 8 小节低强度 "menu" 变体
- 交付：OGG + M4A 双格式，44.1kHz，主 loop 约 60s，响度 -14 LUFS，循环点零交叉对齐

## 音效清单（映射现有 audio.js 方法名）

| 方法 | 质感描述 | 规格 |
|---|---|---|
| `click()` | 短促 UI 方波咔哒，带轻微机械按压感 | <60ms，干声 |
| `fire()` | 机枪/速射：短噪声爆音 + 低频砰，金属质感、尾音干净，可连发不糊 | ~80ms，2 个音高变体 |
| `rocket()` | 火箭发射：低频嘶声推进 +  sawtooth 下坠呼啸，有重量感 | ~250ms |
| `explode()` | 爆炸：宽频噪声轰 + 90Hz 正弦下潜，卡通化不刺耳，带少量碎片噼啪 | ~400ms |
| `kill()` | 击杀确认：上行双音叮咚（C5→G5），明亮三角波质感加一点金属铃泛音 | ~200ms |
| `pickup()` | 拾取武器箱：轻快上行双音 + 微弱能量充能嘶声 | ~150ms |
| `win()` | 胜利：C5-E5-G5-C6 上行号角式 fanfare，合成铜管 + 铃层，竞技庆祝感 | ~800ms |
| `lose()` | 失败：下行三段锯齿哀叹，柔化滤波避免刺耳，卡通泄气感 | ~800ms |

## 接入约束

- 方法名、参数、调用时机一律不变；`fill` 类无参方法内部可随机选变体。
- 所有采样经统一 gain 总线，`setMuted(true)` 时立即静音（含正在播放的 BGM）。
- BGM 默认音量低于 SFX 约 6dB；首次 `unlock()` 后才允许起播。
