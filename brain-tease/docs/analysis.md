## 结论：什么是「1:1 还原」，什么必须原创

1. **源码里没有引擎代码**，只有 5 条「题目 + 吐槽」文本。因此「玩法规则 1:1 还原」还原的是**品类模式**，不是任何可复用代码：
   - 每关一个「反直觉」谜题场景，答案是刁钻互动（拖拽 / 覆盖 / 找隐藏 / 倒置 / 关弹窗）。
   - 提示系统：首次给一句话线索 → 再给答案演示（spec 的「前置/兜底」）。
   - 过关吐槽文案（`Customs` 的角色）。
2. **必须原创的部分**（spec 已明确，且原素材/IP 名禁止复用）：
   - 原作只有 5 关 → 原创扩到 **24 关**，每 6 关一个多步 Boss 谜。
   - 原作无角色 → 原创「整蛊实验室博士」角色，过关魔性坏笑为 signature。
   - 原作无差异化机制 → 原创「整蛊计」（答错 3 次解锁博士半自动通关，卡关保护）+「速通计时」（本地最佳时间榜，重玩钩子）。
   - 原作提示文案直译会导致中文梗失味 → 全部重写成 en/zh 双语原创文案。
